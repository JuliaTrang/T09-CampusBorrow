## 3.3 Container — C4-L2

- Giữ CTN-01 Web App (React/Vite/TypeScript), CTN-02 API Server (NestJS/Prisma), CTN-03 Database (PostgreSQL/Supabase).
- Có [draw.io](../diagrams/C4-L2_container.drawio) và [PNG](../diagrams/C4-L2_container.drawio.png). Dòng “PNG exports still need draw.io Desktop” trong bản chữ cũ đã lỗi thời so với file có sẵn; chỉ ghi nhận ở đây, không sửa bản cũ.
- Luồng: browser → SPA; SPA → API qua HTTPS/JSON + cookie; API → DB qua SQL/TLS. Theo ADR-001, `/api/*` rewrite cùng origin; frontend không đọc JWT và không giữ business rules bảo vệ quyền.
- Deployment Vercel/Cloudflare/Supabase là mô tả từ ADR-001; DEP-D #45 và ADR hosting #39 phải khớp sau khi nhóm xác nhận. Cloudflare là hạ tầng, không tự thêm thành CTN-04.
- Bản cũ có bảng `sessions` (ADR-002 cũ). Đã thay: JWT + `token_version` + denylist `revoked_tokens` theo ADR-003 Accepted (đóng I-05); không có bảng session.

## 3.4 Component — CMP-D

Có [draw.io](../diagrams/CMP-D_component.drawio) và [PNG](../diagrams/CMP-D_component.drawio.png). Giữ tên/mã ở bản nháp, không đổi thành tên module cũ trong architecture.md.

| Mã     | Tên giữ nguyên      | Rà thiếu trước khi duyệt                                                                               |
| ------ | ------------------- | ------------------------------------------------------------------------------------------------------ |
| CMP-01 | AuthModule          | SessionGuard/RolesGuard; session đọc cùng Account; không gọi AccountModule gây vòng                    |
| CMP-02 | AccountModule       | Đổi role/khóa/reset và revoke all phải cùng transaction (tăng `token_version`, ADR-003)                |
| CMP-03 | CatalogModule       | Visibility khác operational status; Hidden không tự hủy reservation/loan                               |
| CMP-04 | EquipmentLoanModule | Transaction approval + reserve + reject competing + history; handover/expiry dùng trạng thái hiện hành |
| CMP-05 | RoomBookingModule   | TimetableService dùng Period; Pending không giữ phòng; approval dùng exclusion constraint              |
| CMP-06 | HistoryModule       | Ghi history cùng transaction; API đọc lịch sử phải kiểm tra quyền mà không tạo vòng dependency module  |
| CMP-07 | CorrectionModule    | CO-01–04 và giới hạn reason chỉ là đề xuất đến khi nhóm chốt; không xóa history                        |
| CMP-08 | SchedulerModule     | ExpiryJob gọi CMP-04; lịch chạy/độ trễ chờ I-04; không tự nhả thiết bị đã On loan                      |
| CMP-09 | CommonModule        | PrismaService, Clock, HttpExceptionFilter; không phụ thuộc ngược business modules                      |
